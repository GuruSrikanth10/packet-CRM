# Documentation Standards
- **Always update `ARCHITECTURE.md`**: Before running any `git push` or finalize commands to commit codebase changes, you MUST verify and update `ARCHITECTURE.md` to reflect those changes. This file is the absolute source of truth for the project's design and flow.

# Git Constraints
- **Never push without permission**: You must never execute `git push` directly after making code changes. Always wait for the user to explicitly say "commit and push" or grant permission before pushing any changes to the remote repository.
